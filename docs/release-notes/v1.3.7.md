# Pool Classifier v1.3.7

🚀 [Pool Classifier](https://pool-classifier.relops.mozilla.com) `v1.3.7`
release highlights

- Pool-detail section headings now have stable permalinks, making it easier to
  share a link directly to a specific diagnostic section.

- macOS refresh-rate failures are now classified when the diagnostic reports
  an empty observed refresh rate, instead of appearing as unclassified.
