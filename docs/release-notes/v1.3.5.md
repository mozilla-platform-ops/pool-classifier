# Pool Classifier v1.3.5

🚀 [Pool Classifier](https://pool-classifier.relops.mozilla.com) `v1.3.5`
release highlights

- More reliable collection diagnostics: preserve dormant device-pool
  reactivations, flag interrupted general task collection, and expose
  per-phase classify-all memory peaks.

- Clearer dashboard behavior: overview live-host visibility, corrected
  unclassified heatmap colors, and timezone selections now apply consistently
  to pool-detail times and start-lag trends and persist on the detail page.

- Improved operational robustness: close PostgreSQL pools when Gunicorn
  workers exit, suppress web-classification progress bars and duplicate
  completed-task logs, and use true gzip task-log tails.

- Updated Taskcluster client dependency to 105.0.0.
