# Pool Classifier v1.3.9

🚀 [Pool Classifier](https://pool-classifier.relops.mozilla.com) `v1.3.9`
release highlights

- Truncated task logs no longer abort a pool scan; the unavailable artifact is
  handled like other failed log fetches.

- The overview now refreshes after a partial scan. A dedicated warning icon
  beside utilization identifies a pool with stale data without affecting other
  pool indicators.
