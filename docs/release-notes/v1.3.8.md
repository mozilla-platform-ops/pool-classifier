# Pool Classifier v1.3.8

🚀 [Pool Classifier](https://pool-classifier.relops.mozilla.com) `v1.3.8`
release highlights

- Pool classification now records process and container memory use across its
  phases, including each pool snapshot step. This will help identify where
  memory peaks occur during scheduled scans.

- The Cloud Run memory limit has been raised to 2 GiB to give classification
  headroom while those measurements are collected.
