# Pool Classifier v1.3.12

🚀 [Pool Classifier](https://pool-classifier.relops.mozilla.com) `v1.3.12`
release highlights

- The pool overview now pairs the seven-day p95 start lag with the worst hourly
  p95 in that window, making short lag spikes visible alongside the overall
  trend.
- The overview highlights critical and high priority failures from the last
  24 hours. It also uses a clearer Task success label and drops the little-used
  Alerting and Err/Host columns.
- Pool detail pages show severity for recent failures, so priority counts can
  be traced to individual tasks. Recent task outcomes remain available farther
  down each detail page.
