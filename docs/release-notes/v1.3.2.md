# Pool Classifier v1.3.2

🚀 [Pool Classifier](https://pool-classifier.relops.mozilla.com) `v1.3.2`
release highlights

- New experimental capacity-scenarios API:
  `GET /api/v1/pools/{provisioner}/{worker_type}/capacity-scenarios`

  It replays observed workload to model how adding healthy hosts could affect
  start lag, including modeled p50/p95 lag, target attainment, peak queue
  depth, estimated minimum additional hosts, calibration context, and
  turnaround-time sensitivity.

  This is a read-only planning tool—not automatic provisioning or a complete
  Taskcluster queue simulation.

- Better utilization data quality: partially covered windows now show metrics
  calculated from observed periods, clearly labelled with coverage percentage
  and `status: "partial"`. The dashboard visually distinguishes partial from
  complete data.

- More accurate collection continuity: normal idle-to-active worker transitions
  no longer appear as coverage gaps; genuine missing-overlap cases are still
  recorded for diagnosis.
