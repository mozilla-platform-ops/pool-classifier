# Pool Classifier v1.3.11

🚀 [Pool Classifier](https://pool-classifier.relops.mozilla.com) `v1.3.11`
release highlights

- Classification now checks only task runs in each recent-task window against
  the database, in bounded indexed batches. It no longer loads every historical
  terminal task-run ID into each pool classifier at startup.

- We will compare production scan duration and memory with v1.3.10 before
  deciding whether to adjust the lookup batch size or address the separate
  overview snapshot memory peak.
